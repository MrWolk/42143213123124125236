# ALLINMenu 1.0.2
Paper 26.2 / Java 25

## Игрок
/menu

Главное меню содержит:
- подробные профессии с командами просмотра прогресса;
- экономику, банк, торговлю и аукцион;
- дома/аренду;
- прокачку верстака;
- фракции и их команды;
- отдельный многостраничный справочник команд;
- донат и кликабельную ссылку https://allinonline.easydonate.ru;
- Мастеров обмена с 30-секундной телепортацией.

## Донат
Клик по кнопке в GUI закрывает меню и отправляет в чат зеленую кликабельную кнопку
«ОТКРЫТЬ МАГАЗИН». Minecraft-клиент открывает URL только после клика по текстовой ссылке;
серверный GUI не может принудительно открыть внешний браузер.

## Админ — Мастера обмена
/allinmenu master set <id> <название>
/allinmenu master rename <id> <название>
/allinmenu master delete <id>
/allinmenu master list
/allinmenu reload

Точка `set` сохраняется по текущему местоположению администратора.
Телепортация занимает 30 секунд; изменение X/Y/Z отменяет ее, поворот камеры разрешен.

## Настройка
plugins/ALLINMenu/menu.yml — все разделы, тексты, команды и donate-url.
plugins/ALLINMenu/masters.yml — точки мастеров.
plugins/ALLINMenu/config.yml — таймер и сообщения.
